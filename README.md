# Telegram-бот

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. `cp .env.example .env` и вставь токен в `BOT_TOKEN`.
3. `pip install -r requirements.txt`
4. `python -m bot.main`

Хост нужен только для работы 24/7 (VPS, Railway, Fly.io); для разработки хватит своего компьютера.
